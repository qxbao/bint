## TUI-specific limitations

- `TestMilestoneApproveThirtyItemsFromInbox` is evidence that the test fixture can traverse a 30-item flow. It does not establish the plan's “under one minute” human threshold.
- Golden files at fixed dimensions prove deterministic output snapshots; they do not prove the owner approved the palette or that screenshots work in a real terminal.
- Plan-recorded items such as actual editor launch, `go install`, `syscall.Exec` restart, Windows runtime, VHS screenshots and testing with 2–3 unfamiliar users remain listed in [deferred.md](deferred.md#def-004).
- The project docs index incorrectly described TUI as “not implemented”; the implementation stages are now linked from `docs/README.md` to this report. This correction does not imply every human acceptance check passed.
